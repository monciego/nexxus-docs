Nexxus uses a role-based access system to control which features and actions each user can access.

After logging in, the sidebar provides access to the features available to your account. Navigation links are organized into different sections.

## Platform

The **Platform** section contains the main features used for event and production management:

- **Dashboard** — Your main overview of Nexxus.
- **Events** — Create and manage events, talents, rehearsals, and event checklists.
- **Talents** — Manage talent profiles and applications.
- **Clients** — Manage client information and associated events.
- **Call Sheets** — Create, manage, publish, and share call sheets.
- **Calendar** — View events, rehearsals, and calendar entries.
- **Media** — Manage production media. This feature is currently in **Beta**.
- **Messages** — Communicate through direct and group messages.

## Access Control

Users with the appropriate permissions can access the **Access Control** section:

- **Users** — Manage user accounts and their assigned roles.
- **Roles** — Manage roles and their permissions.

## Help and Legal

The sidebar also provides access to:

- **Help** — Access available help and support resources.
- **Legal Documents** — View the applicable legal and policy documents.

## Role-Based Access

Not every user has access to every feature.

Nexxus uses **role-based permissions**, meaning that a user's role determines which features and actions they can access. A role can have permissions such as viewing events, creating call sheets, approving talents, or managing users.

Users can also have multiple roles. When multiple roles are assigned to a user, their permissions are combined.

For example, a user with both the **Moderator** and **Talent** roles receives the permissions provided by both roles.

The available roles and their default permissions are explained in **Roles & Access**.
