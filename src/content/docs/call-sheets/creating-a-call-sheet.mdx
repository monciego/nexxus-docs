---
title: Creating a Call Sheet
description: Build a call sheet for an event, fill in the schedule details, and publish it for the team.
---

This guide walks through creating a call sheet for an event, from the starting
point to publishing.

## Start with a template or a blank call sheet

You can create a call sheet in two ways:

- **From a template.** Choose a [call sheet template](/call-sheets/templates/)
  to start with a standard layout already set up for your team.
- **From scratch.** Start with a blank call sheet and build up the sections
  yourself.

## Link the call sheet to an event

Attach the call sheet to the event it supports, as described in the
[events overview](/events/overview/). Linking keeps the call sheet associated
with the right event and lets it appear alongside the event elsewhere in the
platform.

## Fill in the details

Add the information the team needs for the day:

- Dates and times for the event and its key moments.
- Locations where people need to be.
- Call times for talent and crew.
- Any additional sections required for this particular event.

## Customize sections

Adjust the call sheet to fit the event. You can add, remove, or rearrange
sections beyond the standard layout so the schedule reflects what actually
happens on the day.

## Publish the call sheet

When the details are final, publish the call sheet. Publishing makes it the
official version that can be shared — see
[Sending Call Sheets](/call-sheets/sending-call-sheets/) for how it reaches the
team.
