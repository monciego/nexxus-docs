title: Call Sheets Overview
description: An overview of the Call Sheets module and how call sheets are managed.
---

The **Call Sheets** module allows teams to create, manage, publish, and distribute call sheets for events.

Call sheets contain the information that talent, crew, and other event participants need before and during a production.

## Call Sheet List

Call sheets are organized by **year**, making it easier to find call sheets from a specific period.

You can filter call sheets by:

- **Year**
- **Status**

Available statuses are:

- **Draft** — The call sheet is still being prepared.
- **Published** — The call sheet is finalized and available to authorized users.
- **Archived** — The call sheet is no longer active but remains available for reference.

Select a call sheet to view its details and manage it based on your permissions.

## Templates

Call Sheet Templates allow teams to create reusable layouts instead of building every call sheet from scratch.

Nexxus includes default templates and also allows authorized users to create custom templates based on their workflow.

See [Call Sheet Templates](/call-sheets/templates/) to learn more.

## Creating a Call Sheet

When creating a call sheet, you select an event and a template. Nexxus automatically populates available information from the selected event.

You can then customize the call sheet, preview the result, and save it as a draft or publish it.

See [Creating a Call Sheet](/call-sheets/creating-a-call-sheet/) for the complete process.

## Sending Call Sheets

Published call sheets can be downloaded as PDF files and shared with event participants through messages.

Users with the appropriate permission can send a call sheet to a direct conversation or group conversation.

See [Sending Call Sheets](/call-sheets/sending-call-sheets/) for more information.
