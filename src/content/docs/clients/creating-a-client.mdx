---
title: Creating a Client
description: How to create a client profile and connect it to events.
---

This page walks through setting up a client in Nexxus. Creating a client takes
only a few steps, and once the profile exists you can attach events to it.

## Steps

1. **Add the client's company and contact details.** Enter the organization or
   person's name, along with a primary contact, email address, and phone number.

2. **Save the profile.** The client profile is ready to use and can be updated
   at any time as details change.

3. **Link events to the client.** Add existing events to the client profile so
   the connection between the client and their bookings is recorded.

## Creating events from a client profile

Events can also be created directly from a client profile. This is a convenient
shortcut when a new booking comes in, since the event is set up with the client
already attached.

See [Events](/events/overview/) for more on managing events once they exist.
