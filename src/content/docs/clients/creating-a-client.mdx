---
title: Creating a Client
description: How to create a client in Nexxus.
---

Users with the appropriate permission can create a new client from the Clients module.

When creating a client, you can provide the following information:

- **Company Name** — The name of the client or organization.
- **Contact Person Name** — The primary contact person for the client.
- **Email** — The client's email address.
- **Phone** — The client's contact number.
- **Address** _(Optional)_ — The client's primary address.
- **Billing Address** _(Optional)_ — The address used for billing purposes.
- **Notes** _(Optional)_ — Additional information about the client.
- **Client Since** — The date the client relationship began.

The **Client Since** date is automatically set to the current date when the client is created.

After entering the required information, save the client to create the record.

## Next Steps

After creating a client, open their [Client Details](/clients/client-details/) page to review their information and associated events.
