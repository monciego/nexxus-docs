The **Client Details** page provides a complete overview of a client and their relationship with Nexxus.

## Client Information

The page displays the client's information, including:

- Company Name
- Contact Person
- Email
- Phone
- Address
- Billing Address
- Notes
- Client Since

Authorized users can edit the client's information when changes are needed.

## Associated Events

The Client Details page also displays all events associated with the client.

Each event can be selected to open its **Event Details** page. This makes it easy to move between a client's information and the productions associated with them.

The event history provides a quick overview of the client's activity and the productions they have been involved with.

## Creating Events from a Client

You can create an event directly from a client's profile. This is a convenient shortcut when a new event comes in, as the client is automatically associated with the event.

See [Creating an Event](/events/creating-an-event/) for more information about creating and managing events.
