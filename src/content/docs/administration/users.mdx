title: Users

The **Users** module allows administrators to manage user accounts and their assigned roles.

Users can be searched by **name, email address, or User ID**, and the list can be filtered by role and navigated using pagination.

## User Accounts

When a new account is created, Nexxus automatically generates a unique **User ID** using the `NX` prefix, such as `NX0001`.

A user account contains:

- **Full Name**
- **Email Address**
- **Temporary Password**
- **Confirm Temporary Password**
- **Role**

The temporary credentials are sent to the user so they can log in and change their password.

Users can be assigned one or multiple roles. When multiple roles are assigned, the permissions from all assigned roles are combined.

## Superadmin Accounts

Superadmin accounts are protected from normal account management.

Only the superadmin's password can be changed through the system. Changes to the superadmin's name or email address require contacting the Nexxus developer.

Superadmin details are hidden from normal users by default. Superadmins can view other superadmin accounts.

Removing a superadmin account requires contacting the Nexxus developer.
