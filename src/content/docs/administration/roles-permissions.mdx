Nexxus uses **role-based permissions** to control what users can access and what actions they can perform.

Each role contains a set of permissions. Assigning a role to a user automatically gives that user the permissions assigned to the role.

## System Roles

Nexxus includes five system roles by default:

- **Superadmin** — Has full access to the entire system and all available permissions.
- **Admin** — Has broad access to manage events, clients, talents, call sheets, users, and other operational areas.
- **Moderator** — Handles day-to-day event and production activities with more limited administrative access.
- **Talent** — Accesses features relevant to their assigned events, schedules, call sheets, and personal profile.
- **User** — A basic system account with limited access.

System roles cannot be deleted or renamed, but their permissions can be modified according to the system's configuration.

## Custom Roles

Administrators can create custom roles and assign specific permissions to them.

Custom roles can be:

- Renamed.
- Edited.
- Deleted.

A custom role cannot be deleted while users are assigned to it. Users must first be reassigned to another role.

   - Delete Clients

5. **Talents**
