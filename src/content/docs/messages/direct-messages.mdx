---
title: Direct Messages
description: How direct messages work in Nexxus.
---

Direct Messages allow users to communicate privately with another user in Nexxus.

Users with the **Direct Message Anyone** permission can search for a user and start a direct conversation.

A user who does not have the **Direct Message Anyone** permission can still receive and reply to a conversation started by another user. The permission only controls who can initiate new direct conversations.

## Managing Messages

Users can:

- Send messages.
- Edit their own messages.
- Delete their own messages.
- Share authorized call sheets in a conversation.

Messages can be updated or removed after they have been sent, according to the available message controls.
