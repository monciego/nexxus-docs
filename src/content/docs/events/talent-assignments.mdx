Talent assignments allow authorized users to add approved talents to an event.

Only talents with an <Badge text="Approved" variant="success" /> status can be assigned to an event.

## Assigning a Talent

From the Event Details page, users with the appropriate permission can select an approved talent and add them to the event.

Assigned talents become part of the event roster and can be included in:

- Rehearsals
- Call sheets
- Event communication
- Event-related schedules

## Event-Specific Performer Needs

Talent onboarding contains information about performer requirements, including dietary restrictions, allergies, green room needs, and special requests.

When a talent is assigned to an event, these requirements can be reviewed and adjusted specifically for that event.

For example, a talent may normally request tea in their green room, but a particular event may require a different arrangement. The event-specific information can be updated without changing the talent's general profile.

## Managing Assigned Talents

Depending on their permissions, authorized users can:

- Assign talents to an event.
- Edit an assigned talent's event-specific information.
- Remove a talent from an event.

Removing a talent from an event does not delete their talent profile from Nexxus.
