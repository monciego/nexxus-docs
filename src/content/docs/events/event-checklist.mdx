---
title: Event Checklist
description: How to use event checklists to organize and track production tasks.
---

The **Event Checklist** helps production teams organize and track tasks that need to be completed for an event.

Checklist items are organized into categories so teams can separate tasks based on different areas of production.

## Default Categories

Nexxus provides the following default categories:

- **Rehearsals**
- **Production**
- **Invoicing**
- **Contracts**
- **Costumes**
- **Casting**
- **Final**

These categories can be customized to match the requirements of each event.

## Managing Categories

Authorized users can:

- Add new categories.
- Delete existing categories.
- Use the default categories or replace them with categories specific to the production.

Deleting a category also removes the checklist items associated with that category.

## Managing Checklist Items

Each category can contain multiple checklist items.

Users can:

- Add checklist items.
- Delete checklist items.
- Add notes to checklist items.
- Mark items as completed.

Notes can be used to provide additional instructions, reminders, or context for a particular task.

This allows each event to have a checklist that matches its specific production workflow.

## Tracking Progress

The checklist provides a centralized way for the production team to track outstanding tasks and monitor the progress of the event.

Because categories and items can be customized, different events can use different workflows while still using the same checklist system.
