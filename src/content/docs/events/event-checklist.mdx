---
title: Event Checklist
Description: How to use an event checklist in Nexxus to track pre-event tasks and readiness.
---

An event checklist helps you track everything that needs to happen before show day. Instead of relying on memory or scattered notes, you can capture tasks where the whole team can see them.

## Creating checklist items

You can add checklist items to an event for any task that needs completing in the lead-up, such as confirming availability, arranging travel, or preparing materials. Each item represents a single task with its own completion state.

## Marking items complete

As tasks get done, mark their checklist items complete. The event shows which items are finished and which are still outstanding, so there's no ambiguity about what remains.

## Tracking readiness

The checklist doubles as a readiness tracker: as more items are completed, you can see at a glance how prepared the event is. It's a straightforward way to confirm nothing has been forgotten before the event starts.

You can revisit the checklist at any time from the event details page, adding or completing items as plans evolve.
