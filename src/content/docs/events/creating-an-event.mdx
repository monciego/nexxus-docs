title: Creating an Event
description: How to create an event in Nexxus, from basic details to a fully planned engagement.
---

Events are usually created by agency staff and linked to a client. Creating one is the first step in planning any production, booking, or appearance.

## Enter the event basics

Start by adding the core details of the event:

- **Name** — a clear, recognizable title for the event.
- **Type** — for example, a show, shoot, or appearance.
- **Client** — the client the event belongs to.
- **Dates and times** — when the event takes place.
- **Venue** — where it will be held.

## Save the event

Once the basics are in place, save the event. You can update any of these details later from the event details page, and the event will appear wherever agency schedules are shown.

## Flesh out the event

With the event saved, you can build out the full plan:

- [Assign talent](/events/talent-assignments/) and capture each talent's needs.
- [Schedule rehearsals](/events/rehearsals/) and attach the relevant talent.
- [Build the event checklist](/events/event-checklist/) to track pre-event tasks.
- [Create a call sheet](/call-sheets/creating-a-call-sheet/) so the crew and talent have the details they need.

You don't have to complete every step at once — add what you need now and refine the rest as the event comes together.
