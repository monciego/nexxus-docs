Users with the appropriate permission can create a new event from the Events module.

When creating an event, you can provide the following information:

- **Event Code** — Automatically generated by Nexxus.
- **Title** — The name of the event.
- **Description** _(Optional)_ — Additional information about the event.
- **Start Date** — The date and time the event begins.
- **End Date** _(Optional)_ — The date and time the event ends.
- **Client** _(Optional)_ — The client associated with the event. You can select an existing client or choose **No Client**.
- **Venue Name** _(Optional)_ — The name of the event venue.
- **Venue Address** _(Optional)_ — The address of the venue.
- **Status** — The current status of the event.
- **Additional Notes** _(Optional)_ — Any additional information about the event.

## Event Code

Nexxus automatically generates a unique event code when an event is created.

The format is:

```text
EV-YY-####
```

For example:

```text
EV-26-0001
```

In this example, `EV` is the fixed prefix, `26` represents the year 2026, and `0001` is the sequential event number.

The event code is generated by the system and does not need to be entered manually.

## Client

A client can optionally be associated with an event.

You can select an existing client when creating the event or choose **No Client** if the event is not associated with a client.

## Status

New events are created as <Badge text="Draft" variant="note" /> by default.

The available statuses are:

- <Badge text="Draft" variant="note" /> — The event is still being prepared.
- <Badge text="Published" variant="success" /> — The event is active and
  available for normal operations.
- <Badge text="Cancelled" variant="danger" /> — The event has been cancelled.

After providing the required information, save the event to create it.

## Build Out the Event

After creating an event, you can continue building its production plan:

- [Assign talent](/events/talent-assignments/) and manage their event-specific needs.
- [Schedule rehearsals](/events/rehearsals/) and assign the relevant talents.
- [Build the event checklist](/events/event-checklist/) to track production tasks.
- [Create a call sheet](/call-sheets/creating-a-call-sheet/) to provide the team with event and production details.

You don't need to complete everything at once. You can create the event first and add or update the remaining information as the production develops.

## Track Production Readiness

The event checklist provides a simple way to track the progress of your production. As checklist items are completed, your team can see which tasks are finished and which still need attention.

You can return to the checklist from the [Event Details](/events/event-details/) page at any time and update it as the production changes.
