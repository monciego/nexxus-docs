---
title: Event Details
description: What you'll find on an event details page in Nexxus and how it connects everything together.
---

Every event in Nexxus has a details page that brings together its core information and all of the records attached to it. It's the single place to review and manage everything connected to one event.

## Core information

The details page shows the essential facts about the event:

- **Name and type** — what the event is and what kind of engagement it represents.
- **Client** — who the event belongs to.
- **Dates and times** — when the event takes place.
- **Venue** — where it will be held.
- **Status** — where the event is in its lifecycle.

## Related records

Beyond the core information, the details page surfaces everything attached to the event:

- **Assigned talent** — the talent attached to the event and their confirmation status.
- **Rehearsals** — scheduled rehearsals linked to the event.
- **Checklist** — pre-event tasks and their completion status.
- **Call sheets** — call sheets created for the event.
- **Media** — media files associated with the event.

## The hub for one event

Because everything connected to an event lives in one place, the details page is your starting point for any work on it. From here you can jump straight into assigning talent, scheduling a rehearsal, updating the checklist, or reviewing the latest call sheet without hunting through the rest of the platform.
