The **Event Details** page is the central workspace for managing a production.

It provides an overview of the event and its related information, including the client, assigned talents, timeline, rehearsals, and event checklist.

## Event Information

The page displays the event's main information, including:

- Event Code
- Title
- Description
- Start and End Date
- Venue
- Status
- Additional Notes
- Assigned Client

If a client is associated with the event, you can access the client's information from the event.

## Talent Assignments

Approved talents can be assigned to an event directly from the Event Details page.

Once a talent is assigned, they become part of the event and can participate in related activities such as rehearsals and call sheets.

Event-specific performer needs can also be managed from the event.

Talents provide information about their requirements during onboarding, such as:

- Dietary restrictions
- Allergies
- Green room needs
- Other special requests

These details are available when managing an assigned talent. They can be adjusted for the specific event when the production requires different arrangements.

This allows the talent's general profile to remain unchanged while providing event-specific requirements.

## Event Timeline

The Event Details page includes a timeline showing important dates related to the production.

The timeline is based on:

- Scheduled rehearsals
- Event start date
- Event end date

This provides a chronological view of the production schedule.

## Rehearsals

Rehearsals can be scheduled directly from the event.

Each rehearsal can have its own attendees, role assignments, location, schedule, and other information.

See **Rehearsals** for more information about creating and managing rehearsals.

## Event Checklist

The Event Checklist helps teams track production tasks associated with the event.

Nexxus provides default checklist categories, including:

- Rehearsals
- Production
- Invoicing
- Contracts
- Costumes
- Casting
- Final

Categories and checklist items can be customized for each event.

See **Event Checklist** for more information.

## Quick Actions

The Event Details page provides quick actions for common event-related tasks.

### Message Group

Users with the **Create Group Message** permission can use the **Message Group** action to open the event's group conversation.

The action is only available when:

- The event is not in <Badge text="Draft" variant="note" /> status.
- The event has at least one assigned participant, such as a user or talent.

If a group conversation has not yet been created, Nexxus automatically creates one when the action is used. The assigned participants of the event are added to the group automatically.

### Create Call Sheet

The **Create Call Sheet** action opens the Call Sheet creation page with the current event already selected.

The event information is automatically populated, allowing you to start creating the call sheet without selecting the event again.

### View Call Sheets

The **View Call Sheets** action opens the list of call sheets associated with the current event.

From there, you can view and manage the call sheets created for the event.

## What's Included

The Event Details page brings together the information and resources associated with the event:

- **Assigned Talent** — View the talents assigned to the event and manage their event-specific needs.
- **Rehearsals** — View and manage rehearsals scheduled for the event.
- **Checklist** — Track production tasks and their completion status.
- **Call Sheets** — View call sheets created for the event.

The page also provides quick actions for common event tasks, such as creating a call sheet, viewing existing call sheets, and opening the event's group conversation when available.
