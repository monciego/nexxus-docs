In Nexxus, an event is a production, booking, or appearance that your agency manages for a client. It can be a show, a shoot, or any engagement with talent attached — and it's the place where all the planning around that engagement comes together.

## The event lifecycle

Every event follows the same general journey:

1. **Create the event** with its basic details, such as name, type, client, dates, and venue.
2. **Assign talent** and capture each talent's event-specific needs.
3. **Schedule rehearsals** and attach the relevant talent.
4. **Build an event checklist** to track pre-event tasks.
5. **Create a call sheet** so everyone knows where to be and when.

## What you can do with an event

- [Creating an Event](/events/creating-an-event/) — set up a new event from scratch.
- [Event Details](/events/event-details/) — review core information and everything attached to an event.
- [Talent Assignments](/events/talent-assignments/) — attach talent and manage confirmations.
- [Rehearsals](/events/rehearsals/) — schedule and manage rehearsals.
- [Event Checklist](/events/event-checklist/) — track readiness before show day.

Events are the hub of your agency's day-to-day work: every client, talent, and schedule in Nexxus eventually connects back to one.
