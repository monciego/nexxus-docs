---
title: Events Overview
description: An overview of the Events module, the event list, and event statuses.
---

The **Events** module is the central workspace for managing productions in Nexxus. It allows authorized users to create and manage events, assign talents, schedule rehearsals, track production tasks, and access event-related call sheets and communication.

## Event List

The Events page provides two ways to view events:

- **Table View** — Displays events in a compact list with their important information.
- **Card View** — Displays events as individual cards for a more visual overview.

You can search for events using their:

- Title
- Description
- Venue Name

Events can also be filtered by their current status:

- **Published**
- **Draft**
- **Cancelled**

The event list uses pagination when there are many events.

## Event Status

Each event has one of three statuses:

| Status        | Description                                              |
| ------------- | -------------------------------------------------------- |
| **Draft**     | The event is still being prepared.                       |
| **Published** | The event is active and available for normal operations. |
| **Cancelled** | The event has been cancelled.                            |

Select an event to open its **Event Details** page, where you can manage the event and its related production information.
