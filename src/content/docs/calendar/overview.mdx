---

The **Calendar** module provides a centralized view of events, rehearsals, and personal calendar entries in Nexxus.

Events and rehearsals automatically appear on the calendar using their scheduled start and end dates. Users can also create their own calendar entries for meetings, reminders, and other activities.

## Calendar Views

You can view the calendar using:

- **Day** — View schedules for a specific day.
- **Week** — View schedules across a week.
- **Month** — View schedules across a month.
- **Year** — View schedules across the year.
- **Schedule** — View upcoming schedules in a list.

## Display Styles

Calendar items can be displayed in three different styles:

- **Colored** — Uses colored blocks to represent calendar items.
- **Dot** — Uses colored dots to represent calendar items.
- **Mixed** — Combines both styles.

## Calendar Access

What a user can see on the calendar depends on their permissions.

Users with **View All Calendar Items** can view calendar schedules across the system.

Users with **Filter Calendar by User** can filter the calendar to view a specific user's schedule.

Without **View All Calendar Items**, users can only see calendar items relevant to them, including:

- Calendar entries they created.
- Calendar entries where they are a guest.
- Events they are assigned to.
- Rehearsals where they are an attendee.

## Calendar Details

Select any calendar item to view its details.

Events and rehearsals display their associated scheduling information, while calendar entries display the information provided when the entry was created.
